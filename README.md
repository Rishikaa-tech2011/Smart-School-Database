\# Smart School Management System — Database



\## Project Overview

This project contains the MongoDB database for a Smart School Management System.



\## Database Details

\- Database Name: smart\_school

\- Database: MongoDB

\- Backup Tool: mongodump

\- Total Collections: 10

\- Total Documents: 23,881



\## Collections

\- students

\- teachers

\- parents

\- users

\- classes

\- subjects

\- attendance

\- marks

\- messages

\- notifications



\## Backup Contents

The database folder contains BSON backup files and metadata files.



\## Restore Instructions

Install MongoDB Database Tools and run:



mongorestore --db smart\_school database/smart\_school



\## Note

This repository contains the database backup only.

Frontend and backend are not included.
